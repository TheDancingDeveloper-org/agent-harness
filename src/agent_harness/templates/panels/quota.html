Spend

Not available. Remaining budget can only come from the provider, and providers frequently do not expose it. One checked example: The Claw Bay has no quota endpoint at all — /quota, /v1/quota and /api/quota all 404, and /v1/usage returns token counts rather than cost windows or remaining headroom.

Where that holds, the counts above are the only budget signal there is, and they are after the fact: a cap is detected when it is hit, never predicted before it. Any admission control that wants to reserve headroom in advance has to absorb that gap. This box says so rather than rendering an empty chart that reads as zero spend.
