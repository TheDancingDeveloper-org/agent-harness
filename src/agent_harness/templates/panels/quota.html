Spend

Not available, and not merely unimplemented. The plan assumed a /quota endpoint over 5-hour and weekly windows. Probed live on 2026-08-02: /quota, /v1/quota and /api/quota all 404. /v1/usage exists but returns token counts — not cost windows, not remaining headroom.

So there is currently no way to ask how much budget is left. The counts above are the only budget signal there is, and they are after the fact: a cap is detected when it is hit, not predicted before it. Anything that needs to reserve headroom in advance (plan §5.3, P3's quota-gated admission) has to absorb that gap. This box says so rather than rendering an empty chart that reads as zero spend.
